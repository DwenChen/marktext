# 正文目录导出

HTML、PDF、PNG 导出及打印支持选择是否包含正文中的目录段。打开导出窗口后，检测到目录时会显示 **显示正文目录段** 开关；默认开启，并记住上次选择。

关闭开关会在导出内容中移除目录标题和目录条目，原文与编辑器侧栏大纲保持不变。PDF 仍保留其余章节的导航书签。

## 识别范围

- 文档正文顶层的标题或独立段落，文字为 `目录`、`目次`、`Table of Contents`、`Contents` 或 `TOC`，后面紧邻一个或多个页内锚点链接列表；支持有序、无序及嵌套列表。
- 文档正文中的独立 `[TOC]` 标记。开启时生成正文目录，关闭时移除标记；目录标题及是否包含首级标题仍可在更多设置中调整。

英文标签和 `[TOC]` 不区分大小写。列表条目需由指向 `#标题锚点` 的链接构成，链接文字可以包含行内格式。代码块、代码示例、引用中的标记，普通导航链接，以及介绍文件目录的正文不会被当作目录删除。

```markdown
# 目录

- [第一章](#第一章)
  - [小节](#小节)

# 第一章

正文内容。

## 小节

小节内容。
```

## 排版一致性

嵌套目录列表在导出时使用与编辑器对应的紧凑段落布局，排除 HTML 列表标签之间的结构换行，同时保留正文软换行、显式换行和松列表间距。GitHub、Academic、Liber 三种内置主题共用这项修复。
