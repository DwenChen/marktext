# 编辑菜单与剪贴板优化

## 当前项目结构

项目是 pnpm 工作区。`packages/desktop` 提供 Electron 桌面应用，`packages/muya` 提供独立 Markdown 编辑引擎，`packages/website` 提供 Next.js 官网。根目录脚本负责协调桌面端构建、测试和本地化。

桌面端采用主进程、预加载桥接和 Vue 渲染进程三层结构：

| 模块 | 职责 | 本次涉及的位置 |
| --- | --- | --- |
| Electron 主进程 | 原生菜单、窗口状态、文件保存和关闭 | `packages/desktop/src/main/menu`、`main/contextMenu/editor`、`main/windows/editor.ts` |
| IPC 类型与桥接 | 在沙箱渲染进程和主进程间传递受类型约束的命令 | `packages/desktop/src/shared/types/ipc.ts`、`shared/types/menu.ts` |
| Vue / Pinia | 侧边栏、编辑器交互、选区快照和文件修改状态 | `packages/desktop/src/renderer/src/components/sideBar`、`components/editorWithTabs/editor.vue`、`store/editor.ts` |
| Muya | 文档块树、选区、剪贴板和可撤销的块转换 | `packages/muya/src/block/contextActions.ts`、`selection`、`clipboard` |

普通文本操作和结构化块操作最终都通过 Muya 更新文档状态。源码模式使用 CodeMirror；桌面菜单会根据编辑模式禁用不适用的块操作。

## 完成的行为调整

1. “段落、格式、视图”置于侧边栏顶部。展开时横向排列，收起为窄侧栏时纵向排列。它们复用当前窗口的原生菜单，因此保留快捷键、勾选状态和禁用状态。隐藏侧边栏后，折叠菜单提供这些入口。
2. 窗口菜单同步置顶与全屏勾选，缩放菜单显示当前百分比，达到缩放边界后禁用对应动作。菜单重建时保留置顶与全屏状态。
3. 桌面应用移除了富文本复制和 HTML 复制的菜单、命令注册、快捷键与 IPC 入口。
4. 应用菜单和 Ctrl+A 一次选中全文。输入框仍使用自身的全选行为。
5. “复制段落”复制完整块的 Markdown 到剪贴板，不插入副本。列表和表格按完整块复制，保留结构信息。
6. 复制时按真实文档顺序排列选区两端，包含同一列表、引用块内的反向选区。元素边界使用字符长度计算偏移，并保留图片节点的特殊光标映射。
7. 只有光标时，右键子菜单可在完整当前块之后插入表格、代码围栏、引用块、数学块、有序列表、无序列表。不会切开光标前后的文字，也不会把新块插入列表项或表格单元格内部。
8. 当前块对应的右键项显示勾选。自 1.1.0 起，取消格式只处理光标最近的匹配层级，保留外层容器和更深层的列表或引用；取消表格格式会将所有行变为普通段落，单元格之间保留制表符。代码、数学和引用内容也完整保留。
9. 有文字选区时，右键子菜单改为“将选中文字转换为”。只转换选区，保留前后未选中的内容；跨段落和反向选区同样适用。转换为表格时按行拆分，制表符或竖线可作为列分隔符。新空表格默认为三行三列。
10. 退出前先提交编辑器最新输入并保存会话备份，只要仍有未保存修改，就提示保存、放弃或取消。启用“恢复上次会话”也不会跳过提示。

六种右键块操作集中在一个子菜单中，编辑、剪贴板和拼写检查维持各自的分组。关闭数学解析选项时不显示数学块入口。

右键打开时保存选区、标签页和文档版本；执行操作前重新解析选区路径，避免菜单切换焦点或文档切换造成错误操作。插入、转换和取消格式都使用可逆的文档替换，因此每次操作可以一次撤销或重做。

## 验证

- 桌面端类型检查和 ESLint；Muya ESLint 与循环依赖检查。
- Muya 单元测试：290 个文件、2516 项通过。
- 桌面端全量单元测试：1084 项首次通过，三项资源争用导致的导入超时在单独复核时通过；36 项按原配置跳过。
- Muya 新增 20 项 Chromium 回归，覆盖六种块操作、反向选区、跨列表项转换、全文选择、完整块复制以及撤销重做。
- Electron 回归覆盖侧边栏菜单、原生右键 IPC、当前块勾选、选区转换、全文复制、段落复制、窗口状态和关闭提示。
- `pnpm run build:unpack` 验证主进程、预加载和渲染进程构建，输出在 `packages/desktop/out`。

浏览器回归在本机使用已安装的 Chromium 1234；测试源码继续使用仓库的标准 Playwright 配置。
