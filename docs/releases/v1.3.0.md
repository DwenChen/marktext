# MarkText 1.3.0

改进文字、段落和图片拖动，修复嵌套列表中的内容丢失与残留序号问题，并新增离线使用帮助和 Markdown 参考。提供 Windows x64 安装程序和免安装 ZIP。

## 编辑与拖动

- 列表内插入或选中图片后，Enter 可继续图片所在层级的下一条列表项，保留已有图片及子列表。
- 选中文字拖动时显示精确落点：竖线插入文字内部，横线在段落或列表边界创建独立内容；列表左侧落点可选择相应层级。整行文字同样可以插入目标光标位置。
- 段落前方浮现标记的拖动使用相同的落点提示；整块移动保留其嵌套内容。Esc 取消后清除提示线和拖动影像。
- 修复复制后拖动嵌套条目导致的渲染异常、内容丢失及撤销失效；移动通过编辑器历史记录提交，支持撤销、重做与保存。
- 移走全部文字后清理原位置的空条目与编号，保留并合理安置已有子列表；有序列表重新编号。
- 选中的图片也能拖到段落光标位置或列表边界；Ctrl／Alt 拖动复制，Esc 取消，支持撤销与重做。图片拖动不会连带移动其子列表。
- 文字拖动过程中和结束后抑制格式快捷栏浮现，图片拖动时收起图片工具和缩放手柄；新的正常选择仍可调用工具。

跨多个内容块的文字选区不直接执行文字拖动；需要移动完整嵌套结构时使用段落标记。落点与手势的详细说明见软件内的“使用帮助”。

## 离线帮助

- 侧栏及完整菜单提供“帮助”，菜单仅保留“使用帮助”和“Markdown 参考”。
- “使用帮助”（F1）介绍软件功能操作，支持关键词搜索、目录跳转，并读取当前窗口实际菜单与自定义快捷键。
- “Markdown 参考”按本软件的编辑、预览和内置导出实现重新编写，覆盖 19 个语法主题，提供原始示例、默认扩展开关及渲染条件。
- 两份手册均内置于程序，可断网阅读；打开或关闭帮助不会把手册内容写入当前文档。参考手册中的示例不会执行 HTML 或加载外部资源。
- 参考手册明确说明：PlantUML 图像仍依赖配置的服务器，远程图片和图表数据仍需对应资源；脚注、高亮等可选语法需在 Markdown 设置中开启。

## 下载

- `marktext-win-x64-1.3.0-setup.exe`：Windows x64 安装程序。
- `marktext-win-x64-1.3.0.zip`：免安装压缩文件，解压后运行 `marktext.exe`。
- `SHA256SUMS.txt`：安装程序与 ZIP 的 SHA-256 校验值。
- `build-info.json`：版本、源代码提交及 GitHub Actions 构建地址。

本次功能测试仅覆盖改动相关的列表、文字与图片拖动、工具栏、离线帮助和受影响的菜单布局，同时执行类型、静态检查及生产构建。发布前核对云端构建来源、附件大小与摘要。本地验证继续复用已有原生模块，云端构建准备与目标 Electron 匹配的原生依赖。
