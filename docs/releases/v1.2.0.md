# MarkText 1.2.0

新增右键菜单 **在上一层级键入** 和 **在下一层级键入**，方便在已有嵌套结构中继续写作。提供 Windows x64 安装包和免安装 ZIP。

## 更新内容

- 在二级列表条目中选择“在上一层级键入”，会在所属一级条目之后创建新的一级列表条目并定位光标，保留已有子列表和兄弟条目。继续按 Enter 仍在一级列表中输入。
- 仅当当前条目或引用内已有子列表、引用、表格、代码或数学块时，显示“在下一层级键入”。多处子块优先进入光标后最近的子块，否则进入前面最近的子块。
- 进入子列表会在末尾继续创建条目；进入引用会继续创建段落；已有空输入位置会复用。进入表格、代码或数学块时，定位到现有内容末尾。
- 上移一次只切换一个格式层级；从顶层列表或引用上移，会回到文档正文。没有对应层级的菜单项不显示，有文字选区时两个入口均隐藏。
- 保留有序列表起始编号与任务列表状态，新建任务条目默认为未完成。新增输入位置支持一次撤销／重做，菜单执行保留文档和选区版本校验。
- 更新 README、使用说明与定向测试流程；本地启动继续复用已有原生模块构建。

这些操作保留当前条目的全部内容。改变内容的嵌套格式仍使用“在此层级嵌套块格式”或“取消块格式”。详见 [使用说明](https://github.com/DwenChen/marktext/blob/v1.2.0/docs/BLOCK_NESTING.md)。

## 下载

- `marktext-win-x64-1.2.0-setup.exe`：Windows x64 安装程序。
- `marktext-win-x64-1.2.0.zip`：免安装压缩文件，解压后运行 `marktext.exe`。
- `SHA256SUMS.txt`：两个发行文件的 SHA-256 校验值。
- `build-info.json`：版本、源代码提交和云端构建地址。

构建流程仅运行层级键入、菜单和本地化相关单元测试，以及对应 Electron 回归；编译成功后生成安装包与 ZIP，发布前核对来源与附件摘要。
