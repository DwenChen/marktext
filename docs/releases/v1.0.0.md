# MarkText 1.0.0

本次发布提供 Windows x64 安装包和免安装 ZIP，包含文档主题、GitHub Alerts 与源码模式的改进。

## 更新内容

- 支持 GitHub 的五种 Alert：Note、Tip、Important、Warning、Caution。提示样式跟随文档主题与浅色/深色外观，支持编辑原始标记及撤销、重做。
- HTML/PDF 导出和打印保留 Alert 的标题、图标、边线与正文样式；对齐编辑器和导出页面中的主题链接样式。
- 将侧栏“打开文件夹”按钮高度缩小至 28px。
- 修复源码模式下所见即所得预览与源码叠加的问题，切换时保留文档内容和编辑历史。

## 下载

- `marktext-win-x64-1.0.0-setup.exe`：运行安装向导，可选择安装目录。
- `marktext-win-x64-1.0.0.zip`：解压后运行 `marktext.exe`。如需随目录携带配置，在可执行文件同级新建 `marktext-user-data` 文件夹后再启动。
- `SHA256SUMS.txt`：安装包和 ZIP 的 SHA-256 校验值。
- `build-info.json`：版本、源代码提交和云端构建地址。

## 验证

云端类型检查、代码检查、83 项单元测试和 5 项 Electron 回归测试全部通过。回归覆盖 Alert 编辑、主题与外观切换、HTML/PDF 导出、按钮高度、保存和源码模式切换。

可在 PowerShell 中计算摘要，并与 `SHA256SUMS.txt` 对照：

```powershell
Get-FileHash .\marktext-win-x64-1.0.0-setup.exe -Algorithm SHA256
Get-FileHash .\marktext-win-x64-1.0.0.zip -Algorithm SHA256
```
