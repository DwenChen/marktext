# MarkText 1.4.0

全面重构并优化复杂 Markdown 文档的 PDF、HTML 与 PNG 导出管线，修复数学公式缺失、长图表空白页与裁切、多列表格比例失调与跨页断行、单波浪线范围误删以及自定义纸张单位错误等问题，显著提升导出结果与编辑界面的所见即所得一致性。提供 Windows x64 安装程序和免安装 ZIP。

## PDF 导出重构与分页优化

- **独立离屏打印管线**：PDF 导出改为在隔离的离屏渲染窗口中执行，彻底消除编辑界面样式、深色主题与窗口布局对导出结果的污染，并在生成 PDF 前等待内嵌 KaTeX 字体与图片加载解码完成，修复复杂文档中数学公式大面积不可见（FOIT）的问题。
- **消除空白页与图表裁切**：为 Mermaid、Flowchart、Sequence、Vega-Lite、PlantUML 图表及高图计算实际可打印区域（含页眉页脚与前置标题预留高度），按原始纵横比等比缩放，避免长流程图前出现空白页或底部节点被跨页截断。
- **多列表格与代码块自适应排版**：将表格单元格换行策略调整为 `overflow-wrap: break-word`，并针对 6 列以上宽表自动收紧内边距与字号，保持数值、文件名与短标识符完整不碎裂；表格行启用 `break-inside: avoid` 防止单行被跨页腰斩（超长单行自动放行），多页表格自动重复表头。
- **代码块与 ASCII 图形保真**：对含箱线图／波形字符的 ASCII 图示和略宽代码行自动微调字号，避免折行破坏对齐；中短代码块保持整块不拆页，长代码清单自然跨页流动；短提示框（GitHub Alerts）与引用块保持完整，超长区块允许自然分页。
- **自定义纸张与页边距修复**：修复自定义 PDF 纸张尺寸误按微米传入 Electron `printToPDF` 的问题，统一按毫米转英寸精确传递纸张尺寸与页边距；同步优化系统打印等待字体就绪与页眉页脚容器宽度（消除 `100vw` 溢出）。

## HTML 与 PNG 导出同步优化

- **所见即所得语法与代码高亮统一**：导出引擎对齐实时编辑器的双波浪线删除线规则（`~~...~~`），修复中文及技术文档中 `180~265 ns`、`1.39~1.47 µs` 等单波浪线数值范围被误判为删除线并破坏加粗的问题；导出前自动预加载代码块所用 Prism 语言语法，并改用与编辑器一致的浅色高亮配色，消除背景与文字阴影冲突。
- **HTML 导出精简与自适应**：去除重复内联的 `github-markdown-css` 与 Alerts 样式以减小导出体积；完善图表 SVG `viewBox`／`preserveAspectRatio` 与响应式缩放、公式横向滚动保护及宽表紧凑排版，并内置打印样式使浏览器直接打印导出 HTML 同样清晰。
- **PNG 长图导出保真**：消除 `body` 与 `.markdown-body` 双重外边距，修复长代码行被裁剪的问题，并共享宽表、公式、ASCII 图示与图表等比适配逻辑，确保按目标像素宽度输出清晰完整的长图。
