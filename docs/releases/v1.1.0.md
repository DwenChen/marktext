# MarkText 1.1.0

新增右键菜单 **在此层级嵌套块格式**，在当前列表项或引用层级内继续编排内容。提供 Windows x64 安装包和免安装 ZIP。

## 更新内容

- 支持在有序列表、无序列表、任务列表条目以及引用内插入表格、代码围栏、引用块、数学块、有序列表和无序列表。
- 再次选择同类列表或引用会创建嵌套结构；保留当前段落文字、兄弟条目、序号和任务勾选状态，并将光标移动到新块。
- 配套修正“取消块格式”：仅解除离光标最近的匹配层级，保留外层结构和更深层的列表或引用，避免取消子列表时连同父列表一起展开。
- 限制嵌套位置：顶层段落、表格单元格、代码和数学内容内部，以及文字选区，不执行嵌套。数学入口随解析选项显示。
- 支持一次撤销和重做，并复用右键选区、标签页与文档版本校验，避免菜单焦点切换影响插入位置。
- 重写 README，说明新版下载、嵌套用法、项目结构和构建步骤；历史改进与性能记录移至独立文档。
- 云端测试仅运行本次块操作、菜单和本地化相关单元测试，以及对应 Electron 回归。

规则、示例和空数学围栏的说明见 [嵌套块格式使用说明](https://github.com/DwenChen/marktext/blob/v1.1.0/docs/BLOCK_NESTING.md)。

## 下载

- `marktext-win-x64-1.1.0-setup.exe`：安装向导，可选择安装目录。
- `marktext-win-x64-1.1.0.zip`：解压后运行 `marktext.exe`；可在同级创建 `marktext-user-data` 文件夹以携带配置。
- `SHA256SUMS.txt`：安装包和 ZIP 的 SHA-256 校验值。
- `build-info.json`：版本、构建提交和云端构建地址。

发布流程在定向测试和编译成功后生成安装包与 ZIP，并核对上传文件的大小和 SHA-256 摘要。
