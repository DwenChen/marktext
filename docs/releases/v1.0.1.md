# MarkText 1.0.1

本次维护更新修复正文目录在导出后间距增大的问题，并增加正文目录的导出开关。提供 Windows x64 安装包和免安装 ZIP。

## 更新内容

- 修复 HTML、PDF、PNG 中嵌套目录列表出现额外空行的问题，使目录间距、缩进及链接宽度与所见即所得编辑器一致；覆盖 GitHub、Academic、Liber 三种内置文档主题。
- 导出窗口增加 **显示正文目录段** 开关，仅在检测到正文目录时显示，默认开启并记住选择。支持目录标题后紧邻的页内锚点列表，以及独立的 `[TOC]` 标记。
- 关闭开关只控制导出正文中的目录标题与条目，保留原文、编辑器大纲和其余章节的 PDF 导航书签。
- 保留列表正文软换行、显式换行、松列表间距与任务复选框；避免把代码、引用中的 `[TOC]` 示例和普通链接识别为目录。

使用说明见 [正文目录导出](https://github.com/DwenChen/marktext/blob/develop/docs/BODY_TOC_EXPORT.md)。

## 下载

- `marktext-win-x64-1.0.1-setup.exe`：运行安装向导，可选择安装目录。
- `marktext-win-x64-1.0.1.zip`：解压后运行 `marktext.exe`。如需随目录携带配置，在可执行文件同级新建 `marktext-user-data` 文件夹后再启动。
- `SHA256SUMS.txt`：安装包和 ZIP 的 SHA-256 校验值。
- `build-info.json`：版本、源代码提交和云端构建地址。

## 验证

云端类型检查、代码检查、83 项相关单元测试和 7 项 Electron 回归全部通过，覆盖目录识别与显示/隐藏、软换行、GitHub Alerts、启动和源码模式。安装文件在所有检查通过后生成。

本地逐项对照三种主题的目录高度、缩进和链接宽度，并检查实际导出的 HTML、PDF 和 PNG，以及目录隐藏后的正文、链接和 PDF 章节书签。

可在 PowerShell 中计算摘要，并与 `SHA256SUMS.txt` 对照：

```powershell
Get-FileHash .\marktext-win-x64-1.0.1-setup.exe -Algorithm SHA256
Get-FileHash .\marktext-win-x64-1.0.1.zip -Algorithm SHA256
```
