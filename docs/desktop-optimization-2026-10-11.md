# 桌面编辑体验优化记录

日期：2026-10-11。当前桌面包版本：`0.22.0-dev`。

## 项目梳理

项目采用 pnpm 工作区。根目录管理共享工具和脚本，应用代码位于各包内部。

| 包或目录                                           | 职责                                              | 本次涉及范围                               |
| -------------------------------------------------- | ------------------------------------------------- | ------------------------------------------ |
| `packages/desktop/src/main`                        | Electron 主进程：窗口、偏好、文件读写、菜单和导出 | 设置初始化、渲染器就绪通知、PNG 导出       |
| `packages/desktop/src/preload`、`src/shared/types` | 沙箱渲染器的桥接接口和跨进程类型                  | 补充偏好读取与就绪通知的 IPC 合同          |
| `packages/desktop/src/renderer/src`                | Vue 3、Pinia：标签、编辑器、标题栏、设置和大纲    | 六项界面和导出改进                         |
| `packages/muya`                                    | Markdown 编辑引擎、文档模型、解析和渲染           | 复用现有引擎和文档状态缓存，无引擎源码改动 |
| `packages/website`                                 | 独立 React 网站                                   | 本次未涉及                                 |
| `scripts`                                          | 工作区工具                                        | 新增复用已打包运行时的脚本                 |

界面卡顿主要涉及渲染器时序、布局变化和启动加载路径，因此本次改动集中在桌面包。现有 Electron 运行时及其原生二进制继续复用。

## 六项改进

### 1. 标签切换

点击后先绘制选中反馈，再切换文档；连续点击会替换待切换目标，避免加载中间文档。动画只作用于颜色、透明度和下划线变换。关闭按钮与未保存标记保持固定占位，避免标签宽度跳动。

编辑器恢复滚动位置时不再先隐藏一帧，减少切换时的空白闪烁。保留各文档的光标、撤销历史和滚动位置，并支持系统的减少动态效果设置。

新文档按发起打开的顺序追加到标签栏末尾。主进程仍并行读取文件，但按请求顺序向界面发布结果，避免读取较快的文件抢先插入。后续打开保留手动拖动后的顺序；重复打开只切换到已有标签；单个文件读取失败不会阻止后续文件打开。

关键文件：`components/editorWithTabs/tabs.vue`、`editor.vue`、`packages/desktop/src/main/windows/editor.ts`。

### 2. 标题栏文字

标题位于正文显示区最上端，以正文栏的水平中心为基准。它直接跟随正文栏布局，在拖动侧边栏、折叠为图标栏、隐藏侧边栏以及调整窗口大小时同步居中。未保存标记采用对称占位，避免标题文字偏移。

标题随当前标签更新，并按正文栏可用宽度将字号从 14px 缩小至最低 10px；仍放不下时显示省略号，悬停可查看完整路径。左右控件保留空间，窗口菜单仍固定在窗口左上角。

同时修正 Windows 路径分隔符识别，避免将整条路径当作文件名。

关键文件：`components/titleBar/index.vue`。

### 3. 表格居中

在正文风格之外增加共同规则，使表格整体水平居中。此规则覆盖所有四种正文风格及四种界面主题，也应用于带样式的 HTML、PDF 和 PNG 导出。单元格仍遵循 Markdown 自身的对齐设置。

关键文件：`assets/styles/documentStyles.css`、`util/exportHtml.ts`。

### 4. 设置窗口

设置页面改为按需加载，避免打开设置时加载编辑器页面。界面挂载前完成偏好、语言资源和主题初始化，Element Plus 组件也使用对应中文区域设置。

异步页面加载后由渲染器发送就绪通知，再启动文档初始化，保证延后挂载不会丢失首批文档消息。语言切换采用请求序号，避免较早的加载结果覆盖较新的语言选择。

关键文件：`router/index.ts`、`main.ts`、`i18n/index.ts`、`Main.vue`，以及主进程窗口和偏好模块。

### 5. PNG 长图导出

使用“文件 → 导出 → 导出为 PNG”。导出设置的页面选项中可设置图片宽度，范围为 320–2400px，默认 1200px；可继续选择导出主题和字体。

导出使用完整文档 HTML，在独立离屏窗口等待字体和图片后捕获整页，包含视口以外的内容。源码模式下会先同步当前输入，避免导出旧内容。临时窗口和文件在完成或失败后释放。

单张图片的任一边不超过 32767px，总面积不超过 8000 万像素；超出时显示中文错误提示。离屏导出最长等待 45 秒。

关键文件：`src/main/utils/exportImage.ts`、`src/main/menu/actions/file.ts`、`components/exportSettings/index.vue`、`components/editorWithTabs/editor.vue`。

### 6. 大纲按级折叠

在大纲标题右侧选择“显示至 H1”至“显示至 H6”，可一次折叠更深层标题；“全部展开”恢复展开。折叠后仍可单独展开节点。每个打开文档分别保存本次会话内的级数和手动展开状态。

关键文件：`components/sideBar/toc.vue`、`util/tocKeys.ts`。

以上渲染器相对路径均基于 `packages/desktop/src/renderer/src`。

## 复用原生模块的预览版

下列预览路径记录本地验证时的产物。云端完整构建后的安装包、ZIP 和免安装目录统一放在 `dist`，免安装入口为 `dist/win-unpacked/marktext.exe`。清理旧预览后，复用脚本默认使用这个最新目录作为原生模块来源，仍可通过参数指定其他已打包版本。

可运行文件：`dist/optimization-preview/win-unpacked/marktext.exe`。运行或复制时需保留整个 `win-unpacked` 目录。

复用来源：`dist/performance-preview/win-unpacked`。打包仅替换应用构建产物和语言资源，校验了 6 个原有原生二进制的 SHA-256，保持完全一致。无需安装 Visual Studio C++，也未运行原生模块重编译。

复用脚本：`scripts/package-existing-runtime.mjs`。在仓库根目录使用已有依赖生成新预览目录：

```powershell
& .\node_modules\.bin\tsx.cmd scripts\minify-locales.ts
Push-Location packages\desktop
try {
  & .\node_modules\.bin\electron-vite.cmd build
} finally {
  Pop-Location
}
node scripts\package-existing-runtime.mjs dist\performance-preview\win-unpacked dist\optimization-preview\win-unpacked
```

只有主动更新同一个预览目录时才追加 `--update`。脚本拒绝默认覆盖已有目录，输出必须位于仓库的 `dist` 内，且与运行时来源不同。
